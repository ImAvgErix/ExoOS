# Code of Conduct

Be respectful. Assume good intent. No harassment, spam, or deliberate sabotage of other people's machines via PRs or issues.

Maintainers may close issues/PRs that push undisclosed malware, credential stuffing, or unreviewed "just run this as SYSTEM" payloads.

This project optimizes Windows for gaming. That does not include scams, ransomware, or social-engineering installs.
