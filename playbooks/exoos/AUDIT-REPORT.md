## Philosophies

**Extreme (Maximum FPS):** barebones essentials-only. Gaming, browsers, MS Store, Discord/Steam-class apps must work. Everything else that can be stripped for privacy, process count, RAM, latency, and performance is Extreme-gated.

**Balanced:** highest safe ceiling + select aggressive-but-worth-it tweaks. No nuclear strip that breaks a normal desktop (printing optional, search, SMB, Themes, bulk Atlas/Revi merges, BCD timer stack, IFEO, DISM).
