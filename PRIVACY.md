# Privacy

ExoOS is a **local Windows tool**. It does not require an account.

## What ExoOS does on your PC

- Reads system info needed for the UI (CPU/GPU/RAM labels, admin check)
- Writes registry, services, tasks, optional package installs when **you** apply a plan
- May install official redistributables (DirectX, VC++, .NET) from Microsoft or winget sources used by the playbook scripts

## What ExoOS does **not** do

- No Exo cloud account
- No analytics/telemetry service owned by ImAvgErix
- No ads
- Does not upload your library, hardware inventory, or apply logs to us

## Third parties

- **Windows / Microsoft** — OS behavior, optional Store/winget, Defender (if kept)
- **Browser installers** you select (Brave, Helium, Zen, LibreWolf) — their privacy policies apply after install
- **Game clients** you install (Steam, Discord, …) — their policies apply

## Logs

Apply results stay on your machine (UI summary; engine logs only if you capture them). You control backups and restore points.
